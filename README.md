# Delhivery Last-Mile Delay Intelligence Pipeline

## Project Overview
This project analyzes last-mile shipment delivery data to identify delivery delays, understand important delay factors, classify shipments by delay risk, and segment delivery hubs for operational decision-making.

## Objectives
- Clean and prepare shipment data.
- Perform exploratory data analysis (EDA).
- Analyze delivery time and delay patterns.
- Build and evaluate machine learning models.
- Identify important features related to delivery delays.
- Segment delivery hubs based on operational patterns.
- Generate delay-risk predictions and recommended actions for new shipments.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Project Structure
- `data/` — Shipment and hub datasets
- `src/` — Data preparation, modelling, segmentation, and prediction scripts
- `models/` — Saved machine learning models and supporting files
- `outputs/` — Analysis reports, evaluation metrics, and predictions
- `generate_data.py` — Data generation script
- `requirements.txt` — Python dependencies

## Workflow
1. Data cleaning and exploratory data analysis
2. Delivery-time regression analysis
3. Delay classification and model evaluation
4. Hub segmentation
5. Model packaging and prediction for new shipments

## How to Run
Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the project scripts from the project directory using Python.
